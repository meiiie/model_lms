# 13 - Bridge VR Hard-Surface

VR maritime bridge cockpit asset family. Built using two parallel approaches in one session:

1. **v0.x — parametric scaffold**: ground-up parametric modeling with engineering-correct dimensions from SOLAS V/22, IMO MSC.CIRC.982, ABS Bridge Ergonomics, and IMO MSC.232(82). Useful as a dimensional validation reference.
2. **v2.0+ pivot — base on `06_Bridge_Cabin`**: re-uses production assets (ship wheel, magnetic compass, engine telegraph, ECDIS, AIS, radar, alarm panel) already shipped under `06_Bridge_Cabin/source/Bridge_FullScene_v1.1.blend`, adds screen UI textures, polished materials, and a Poly Haven HDRI sky environment. **This is the recommended base going forward.**

## Status

Slot 13 was previously occupied by an image-to-depth-relief experiment that was retired in commit `9f38353`. The `13_Bridge_VR_HardSurface` family takes the slot afresh.

## Engineering dimensions baseline

Verified against SOLAS V/22, MSC.CIRC.982, ABS, MSC.232(82). Key values used in scaffolding:

- Wheelhouse interior: 10 × 6 × 2.25 m (W × D × H)
- VR HMD eye height (conning): **1.80 m** (1.60 m minimum allowed)
- Reference person stature: 1.90 m at 0.75 m aft of front bulkhead
- Front window inclination: 15° (within 10°-25° SOLAS allowed)
- Window lower edge ≤ 1.0 m / upper edge ≥ 2.0 m above deck
- Console max envelope: 1.6 × 0.85 × 1.2 m (W × D × H)
- ECDIS chart presentation: ≥ 270 × 270 mm

See `research/RESEARCH_NOTES.md` for the full table with section references.

## Quest 3 performance budget (target)

- 200-400 draw calls/frame, ≤ 750 K tris in primary view, ≥ 72 FPS
- ASTC textures, hero textures ≤ 2 K, foveated rendering recommended
- v2.0 pivot scene: 201 objects, 13,225 polys, 58 named materials — comfortably within budget
